# 程序要求

清单中会议决策规则包含涉及会议、决策顺序、决策角色和角色说明；使用原数字编号精确定位。未知规则编号不能模糊替换。MD 类别 ID 不能用于查具体条目。

党委会前置研究不等于董事会最终批准，总经理办公会不能未经依据替代其他决策机构。记录事件、日期、决定范围、依据、授权来源和材料位置，不从报告措辞推定有效表决。

原 Step4 示例把“未提及董事会决议”作为不合规，本包采用更审慎区分：未提供证据为信息不足；材料明确证实未履行且应履行、或层级／顺序错误，才是确证程序不合规。已确认缺失的必要程序可保留 missing_procedures，同时 status=NON_COMPLIANT，交主 skill 决定否定意见或人工复核，不无限补件。
