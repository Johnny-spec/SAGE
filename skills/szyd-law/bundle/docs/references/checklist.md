# 材料核对

必要材料必须源于已识别事项、适用规则和分支风险，不能统一要求所有事项都提供资产评估、出资协议、党委会决议。记录“为什么需要”，不编造文件编号。

文件分为：仅被提及、已提供、已查看可核对、内容不足／无效。required_documents、provided_documents、missing_documents 用一致名称；needs 可以要求材料缺失的页、附件、签署或具体事实。内容无法访问时说明限制，由宿主解决技术访问问题，不伪装为查验完成。

新增附件目录本身可能不解决实质缺口，agent 必须查看并重新审查；resume 不因新增文件名自动将其验证为 true。
