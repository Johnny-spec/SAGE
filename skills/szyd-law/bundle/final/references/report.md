# 正式报告体例

标题：《关于【已识别事项名称】的合法合规性审核意见书》。不得猜测事项名称，使用已提供材料的名称或经前序确认的描述。

引言说明审核依据、审核材料来源及本次三重一大合法合规性审核范围。

一、决策事项基本情况：基于 identification 与 capital，客观写背景、类型、主体、资金／项目情况，不加评价。

二、主要依据：依次写（一）法律、法规及部门规章、（二）党的规章制度、（三）公司章程与内部制度。只能列前序已识别且核实的依据；未涉及／未提供明确说明，不能补条目。

三、法律分析：依次写（一）所涉法律关系分析、（二）程序合规性分析、（三）内容合规性分析。分别复述 legal、procedures、capital 的分析与限制，不能自行推定。

四、审核结论：准确复述主 skill review，审慎措辞。已确认不合规时写否定意见并保持 REJECTED，不写“所有 Gate 通过”或“无保留意见”。条件性意见只包含前序确认的条件，不能掩盖关键缺件。

五、建议：仅使用前序 capital/procedures/materials 提出、review 采用的建议。没有建议可说明未提出新增建议，不制造事项。

使用正式中文、克制客观。信息限制按前序写“根据已提供信息”等，不能用此措辞掩盖事实缺口。不新增出具单位、签字、日期、编号、律师资质或实际行政审批事实。
